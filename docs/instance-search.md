# 需求文档：Instances 列表搜索功能

## 1. 概述

在首页 Instances 列表区域的标题和列表项之间，新增一个始终可见的搜索框，支持对实例的模糊搜索过滤。

## 2. UI 设计

- **位置**：Instances 标题行正下方、第一个列表项上方，始终占据一行
- **宽度**：与列表等宽
- **占位符文字**：`/ Search...`（提示 `/` 快捷键）
- **高度**：1 行
- **聚焦样式**：边框高亮（accent 色），光标闪烁
- **失焦样式**：边框变暗，placeholder 文字可见

## 3. 交互行为

| 操作 | 行为 |
|------|------|
| 按 `/` 键 | 聚焦搜索框，进入搜索态 |
| 输入文字 | 同步过滤实例列表（无需防抖，纯内存操作） |
| 按 `Esc`（有搜索词时） | 清空搜索词，显示全部实例，焦点回到列表 |
| 按 `Esc`（无搜索词时） | 焦点回到列表 |
| 按 `Enter` | 聚焦列表（确认当前选中项） |
| 搜索态中按 `j/k` | 作为普通字符输入搜索框 |
| 浏览态中按 `j/k` | 上下移动列表选中项 |

## 4. 搜索逻辑

- **匹配字段**：Title、Description、Branch
- **匹配方式**：大小写不敏感的子字符串模糊匹配
- **空搜索**：搜索框为空时显示全部实例（等同于未过滤状态）
- **无匹配**：列表区域显示 "No matching instances" 提示文字
- **高亮匹配**：在实例的 Title / Description / Branch 中，将匹配的子串用不同颜色高亮显示
- **选中状态**：搜索过滤导致当前选中实例被过滤掉时，自动选中第一个匹配项

## 5. 状态持久化

- 应用重启后搜索框始终为空，不跨会话保留搜索词

## 6. 技术实现要点

- 搜索过滤为同步操作，不需要防抖
- 搜索框使用 Bubble Tea 的 `textinput` 组件
- 在 `ui/list.go` 的 `List` 组件中集成搜索框渲染
- 在 `app/app.go` 中新增 `stateSearch` 状态或利用现有状态机处理搜索态的键盘事件
- 搜索过滤逻辑：维护一个 `filteredInstances` 切片，搜索词变化时重新计算
- 高亮匹配子串：在 `ui/list.go` 的 `Render` 方法中，对匹配字段中命中的子串应用不同样式
